## 2. 遊戲模式

### 邊牧之家（主頁）

打開 App 先回到家，邊牧在房間裡等你。

- **第一次使用**：先幫邊牧取名字、用滑動開關選想種哪些字（各等級、德奧瑞說法）、選每天的量，之後打開就直接進家裡。
- **房間就是選單**：門 → 農場、書櫃 → 翻卡、黑板 → 文法練習、月曆 → 紀錄、齒輪 → 設定、碗 → 餵食，右下「去澆水」直接開始今天的複習。
  下方仍有「家／農場／翻卡／紀錄」分頁。
- **名字平常不顯示**，不然太雜：電腦滑鼠移上去、手機長按才出現。點邊牧會跳出牠的名字和好感度。
- **邊牧會自己活動**：在地毯上走來走去、坐下、眨眼搖尾巴、到狗窩睡覺（冒 Z）、叼網球玩、坐在窗邊看外面；
  有作物該澆水時，偶爾會跑到「去澆水」旁邊頭上冒水滴來討。
- **窗外**：時間跟系統時鐘（早上、白天、傍晚、晚上，晚上有星星月亮、房間變暗），季節跟系統日期（春花、夏綠、秋天金黃、冬天下雪），
  天氣隨機（同一個半天固定；只有冬天會下雪）。外面田裡的乾土和水滴跟農場的狀態一致。

### 好感度

好感度只會增加，用 5 顆心顯示，每多一顆心邊牧就學會一個新動作。

| 怎麼增加 | 好感度 |
|---|---|
| 摸摸牠（點邊牧） | 每次 +1，一天前 3 次 |
| 澆完當天的水（有澆水或播種，而且今天沒有剩下的） | +3，一天一次 |
| 餵果實 | 每顆 +2，一天最多 10 顆 |

| 心 | 需要的好感度 | 學會 |
|---|---|---|
| 1 | 5 | 自己叼網球玩 |
| 2 | 15 | 坐在窗邊看外面 |
| 3 | 35 | 你回家時從門口跑來迎接 |
| 4 | 70 | 點地板，牠會走過去 |
| 5 | 120 | 點網球丟給牠撿 |

大約第一天就有 1 顆心，每天照顧的話三週左右滿心（剛好是作物開始結果、有果實可以餵的時候）。

### 閃卡

閃卡是複習的基本形式，有兩種用法：

- **澆水（排程複習）**：從農場點「去澆水」，出現的是今天該複習的字，結果會影響作物成長。
- **自由翻卡**：自己挑範圍（等級、字母、熟練度、錯題本）隨意翻，不影響農場排程。

卡片設計：

- **正面**：德文單字（名詞不顯示冠詞，讓你先想冠詞）。也可以反過來，正面顯示中文／英文，想德文。
- **背面**：冠詞（用果實顏色標示）與複數、動詞三態、中英意思、例句與翻譯、發音按鈕。
- **操作**：點一下翻面；看完按「不會／模糊／記得」，也可以左滑不會、右滑記得。
- **發音**：用瀏覽器內建的德語語音朗讀單字和例句，不用另外付費。

### 單字農場（核心，閃卡複習的視覺化）

- 每個字是一株作物，新字是種子，每天可設定要種幾顆。
- **澆水＝複習**：用上面的閃卡複習今天該澆水的作物。按「記得」長大一階，「不會」退回一階（不會死），「模糊」不長大但很快會再出現。
- 成長階段對應間隔重複（SRS）的複習間隔：種子 → 發芽 → 幼苗 → 開花 → 結果（約三週後還記得）。
- 該複習的作物土會變乾、頭上出現水滴；太久沒澆會枯黃，複習後恢復。
- **名詞果實顏色＝冠詞**：der 藍莓、die 番茄、das 黃綠色果實。
- **摘果實不會移除作物**：結果的作物會留在田裡，之後隔越來越久（一個月、兩三個月…）才需要再澆一次水。
  每次澆水答對就再結一次果實，收進籃子；答錯的話果實掉落，作物退回開花，很快會再出現。
  這樣已經學會的字也不會在考前被忘掉。
- 所有作物放在同一塊田，上方有「全部／A1／A2／B1」篩選標籤（預設全部，選擇會記住）；該澆水的排前面。

### 快問快答

60 秒計時四選一，可選德→中、德→英、中→德、英→德，連續答對有 combo 加分。

### 例句填空四選一

例句挖空，干擾選項同詞性、同變化形式（名詞同冠詞性別）。

### 跑酷選門

邊牧在草原上跑，前方兩道柵欄門各寫一個詞，滑動換跑道衝進正確翻譯的那道。
衝對趕到一隻羊，連續答對越趕越多，撞錯少一顆心。

### 連接詞與文法練習（2026-11-11 定案，已實作）

自己一套間隔重複複習，**不進農場**；進度在紀錄頁另外顯示。
入口兩個：家裡新增一塊**黑板**（點了進來），以及「翻卡」分頁裡和自由翻卡並排。

**範圍（六組）**

| 組 | 內容 |
|---|---|
| 動詞放最後的連接詞 | weil、obwohl、dass、ob、wenn、als、bevor、nachdem、während、bis、seit／seitdem、sobald、solange、falls、damit、sodass、indem |
| 連接副詞（動詞緊接在後） | deshalb、deswegen、daher、also、trotzdem、jedoch、allerdings、dann、danach、zuerst、schließlich、sonst、außerdem |
| 雙連接詞 | entweder … oder、sowohl … als auch、weder … noch、je … desto／umso、zwar … aber、nicht nur … sondern auch、einerseits … andererseits |
| zu＋不定式 | um … zu、ohne … zu、statt … zu；um … zu 和 damit 對照（同主詞／不同主詞） |
| 關係代名詞 | 主格、受格、與格（der／den／dem、die／der、das／dem、複數 die／denen），加上介系詞＋關代（mit dem、in der…）；**不練** dessen／deren |
| 屬格介系詞 | wegen、trotz、während、statt、innerhalb、außerhalb；練冠詞與陽性／中性名詞加 -(e)s |

**題型（混著出）**

- **閃卡**：正面德文＋語序小標記（例如 `obwohl ＋ …動詞`），背面中文、英文意思和例句，例句的動詞用顏色標出位置。方向跟設定頁一樣。關代和屬格介系詞的卡片改成看規則（例如 dem＝陽性／中性 與格）。
- **四選一**：選連接詞或選形式。干擾選項故意放意思相同、語法不同的（weil／denn／deshalb／wegen）。
- **排語序**：點字塊排出後半句，練動詞位置。
- 答完一律解釋為什麼（例如「deshalb 佔第一位，動詞緊接在後，主詞跑到後面」；關代「性別看前面的名詞，格位看在子句裡的角色」）。
- 重點對比題：weil／deshalb／wegen、obwohl／trotzdem／trotz、während 連接詞／介系詞、statt … zu／statt＋屬格、wenn／als、um … zu／damit。

**內容**：例句全部原創、三語，分批做（格式見 `docs/content-guide.md`）。
已完成 50 個文法點、252 題（`data/grammar/g001`～`g007.json`），每個文法點 5～6 題，之後的題目照檔名與順序帶出：
- 連接詞（動詞放最後）：weil、obwohl、damit、dass、ob、wenn、als、bevor、nachdem、während、bis、seit／seitdem、sobald、solange、falls、sodass、indem
- 連接副詞：deshalb、trotzdem、deswegen、daher、also、jedoch、allerdings、dann、danach、zuerst、schließlich、sonst、außerdem
- 雙連接詞：entweder … oder、sowohl … als auch、weder … noch、je … desto、zwar … aber、nicht nur … sondern auch、einerseits … andererseits
- zu＋不定式：um … zu、ohne … zu、statt … zu
- 關係代名詞：主格、受格、與格、介系詞＋關代
- 屬格介系詞：wegen、trotz、während、statt、innerhalb、außerhalb
- 全部寫完後請另一輪逐題檢查過德語（文法、答案唯一、干擾選項一定錯、排語序只有一種）。還沒做：so … dass 對比、innerhalb／außerhalb ＋ von 的用法、dessen／deren（本來就不練）。

**怎麼排程**

- 複習的單位是「文法點」（例如 weil、關代與格），每個文法點有自己的間隔重複進度，演算法和節奏設定跟單字共用。
- 新的文法點每天自動帶出 3 個，照「成對比的排在一起」的順序（weil → deshalb → wegen → obwohl → trotzdem → trotz → …）；
  練完可以按「再學 3 個新的」。
- 新文法點先看閃卡，接著馬上做一題；之後每次複習照順序換題型和句子，全部出過一輪再看一次閃卡。
- 四選一、排語序答對算「記得」、答錯算「不會」（隔三題再出現，換一題）；閃卡自己按不會／模糊／記得。
- 練完可以「隨意練習」：從學過的文法點隨機出 10 題，不影響排程。
- 有文法該複習時，家裡的黑板右上角會貼一張黃色提醒。

### 邊牧之家之後要加的

- 跑酷趕到的**羊**是貨幣，用來買項圈、帽子、狗屋等裝飾，放在家裡。

## 3. 分類與篩選

- **難度等級**（2026-11-11 已實作）：A1、A2、B1 各一個「無／中／高」滑動開關，第一次使用和設定頁都有（設定頁「種子袋」）。
  新字照比例從各等級抽：高＝3、中＝1、無＝不種。比例是等級之間的，字多的等級不會因為字多就佔大多數；某個等級種完了，由其他等級補上。
  預設 A1 高、A2 中、B1 中（約 60% A1、20% A2、20% B1）。設定頁會顯示目前大約的比例。
  舊版的「種子袋」（從 A1／A2 開始、只種 B1）存檔會自動換算成對應的開關。
- **熟練度**：種子、成長中、結果（由複習紀錄自動計算）。
- **地區**（2026-11-11 已實作）：德國、奧地利、瑞士三個開關，各分「無／中／高」，和等級開關放在一起，第一次使用就會看到。
  高＝正常出現（預設）、中＝出現得少一些（權重 1，高是 3）、無＝不種、不出現在自由翻卡。
  一個字的地區看它自己的標記；沒標記但註記「某地區用另一個字」的，算在其餘地區；都沒有就是三地通用，不受影響。
  好幾個地區都用的字取最高的那個。已經種下的字照常澆水。一個字被抽到的機率＝等級比例 × 地區權重。
  其他練習模式做好時沿用同一個判斷（`src/lib/region.ts`）。
- **分級測驗**：決定不做。已經會的字，第一次使用時用等級開關略過；種到時按「太簡單了」就直接長到結果。
- 每個模式都能用這些條件挑題。

## 4. 複習設定

只開放少數幾個好懂的設定，不開放間隔天數這類演算法參數：

| 設定 | 預設 | 說明 |
|---|---|---|
| 每天新種子數 | 第一次使用時自己選 | 每天最多種幾個新字，之後隨時可以改；登記考試日期後改為自動分配 |
| 每天澆水上限 | 100 | 幾天沒複習時，欠的作物會分散到之後幾天，不會一次全部湧上來 |
| 複習節奏 | 標準 | 三段：輕鬆（複習少、比較容易忘）／標準／衝刺（複習多、記得最牢），實際上是調整目標記憶率 |
| 考試日期 | 不設定 | 見下方「考試日期」 |
| 提醒時間 | 不設定 | 用來產生行事曆提醒 |

### 第一次使用：選每天的量

設好想種哪些字之後，讓使用者自己決定每天種幾個新字，有兩種選法：

- **自己選數字**：5／10／15／20／30／自訂。每個選項旁邊顯示「每天大約要花幾分鐘」和「大約幾月幾日種完」，
  讓使用者知道新字數會帶來多少複習量（每天的卡數大約是新字數的 5～10 倍）。
- **我有考試日期**：登記考試日期，由 App 自動分配每天的量（見下一節）。

兩種選法之後都可以在設定裡互相切換。

### 考試日期（自動分配新字）

登記考試日期後，App 每天自動算當天要種幾個新字：

> 今天的新字數 ＝ 還沒種的字 ÷ 到「停止播種日」為止剩下的天數（無條件進位）

- **停止播種日**：預設考前 14 天。最後兩週只澆水、不種新字，讓最後種下的字也能複習幾次。
- **每天重新計算**：哪天沒複習、或手動多種了，之後幾天的量會自動調整，不用自己改。
- **範圍**跟著種子袋（等級與地區開關）走：所有沒設成「無」、還沒種的字。
- **量太多時提醒**：算出來每天超過 30 個時，提示「考前可能種不完」，讓使用者選照算出來的量，
  或設一個每天上限（剩下的字考前就種不完）。
- **澆水上限自動調高**，避免新字多時複習一直往後延。
- **複習間隔不會超過考試日**，考前每個字都會再出現至少一次。
- 農場上方顯示倒數，例如「離考試 87 天・今天種 16 顆」。
- 考試日過後，詢問要登記下一次考試，還是改回自己設定每天的量。

### 新字怎麼來（播種）

- 每天先澆完該澆的水，再種當天的新種子，避免複習越欠越多。
- **種子袋**決定新字的來源：A1、A2、B1 和德奧瑞說法的「無／中／高」開關（見第 3 節）。第一次使用時就讓使用者自己選，之後可以在設定裡改；不做分級測驗。
  也可以指定只種某個等級（例如只種 B1 新字）、某個主題，或錯題本裡的字。
- 同一等級內隨機抽，避免 ab-、an-、auf- 開頭的相似動詞擠在同一天。
- 只會種已經有三語內容的字；內容還在分批補，補好的字會自動加入種子袋。
- 全部種完後就不再有新字，只剩定期澆水（維持記憶）。

大約的時間（B1 新字約 1,790 個；全部 3,019 個則約再多七成）：

| 每天新字 | 種完 B1 新字 | 每天總卡數 | 每天時間 |
|---|---|---|---|
| 10 | 約 6 個月 | 50～100 張 | 10～20 分鐘 |
| 15 | 約 4 個月 | 75～150 張 | 15～30 分鐘 |
| 20 | 約 3 個月 | 100～200 張 | 20～40 分鐘 |
| 30 | 約 2 個月 | 150～300 張 | 30～60 分鐘 |

卡數與時間是估計值，接上 FSRS 後要用實際模擬校正，選每天新字數的畫面也用校正後的數字。

每張卡也可以手動處理：

- **「太簡單了」**：直接長到結果，之後很久才會再出現。
- **「重新學」**：退回種子，重新開始。

複習排程演算法暫定用開源的 FSRS（ts-fsrs，MIT 授權）。
成長階段依目前的複習間隔換算：種子（新字）、發芽（3 天內）、幼苗（3～7 天）、開花（7～21 天）、結果（21 天以上）。

## 5. 複習紀錄頁

- 連續複習天數、今天複習張數與正確率
- 最近 30 天複習日曆
- A1／A2／B1 各自的進度（已結果、成長中、未種）
- 未來 7 天每天要澆水的數量
- 最常答錯的字
- 連接詞與文法（另外一塊）：已學文法點數、今天練習題數與正確率、六組各自的進度（熟練＝複習間隔一週以上、練習中、未學）、最常答錯的文法

### 實作細節（第一版）

- **田的畫面**：每頁 12 格，該澆水的排前面，可左右翻頁，上方用標籤篩選等級；點作物看詳細資料，可以按「太簡單了」或「重新學」。
- **成長規則**：不會退一階、模糊不變、記得至少不退步並跟上複習間隔換算的階段；答對結果的作物收成一顆果實。
- **非名詞的果實**：動詞等其他詞性用杏桃色（冠詞顏色只用在名詞）。
- **枯黃**：逾期超過 3 天。
- **一天的分界**：凌晨 4 點。
- **第一次使用**：用 A1／A2／B1 與德奧瑞說法的滑動開關決定想種哪些字，不做分級測驗。
- **登記考試日期時**：已經排到考試日之後的作物，會平均分散到考前 14 天再澆一次水。
- **邊牧的圖**：原創像素圖（四分之三側坐、一耳立一耳折、臉上白色流星、琥珀色眼睛、白圍脖、白襪、尾巴白尖，暖色的黑白毛），有坐、叼球、走路兩格、趴睡、眨眼、搖尾巴；坐著和趴著會朝牠剛剛走的方向。
- **餵食**：從數量最多的那種果實拿一顆；沒有果實或今天吃飽了會提示。
- **文法練習的資料**：內容在 `data/grammar/gNNN.json`，建置時合併成 `public/data/grammar.json`；
  進度存在 IndexedDB 另外兩個表（`grammar`、`glogs`）。
- **備份相容**：匯出一定帶文法進度；匯入時文法進度可有可無。上一版匯出的備份沒有文法進度，
  匯入後只取代單字進度，目前的文法進度原封不動。備份檔版本號不變，新備份拿到上一版也能匯入（文法那兩欄會被忽略）。
- **例句標記**：`{}` 是這題的重點（連接詞、關代），`[]` 是動詞，答完後動詞用紫色標出位置。
